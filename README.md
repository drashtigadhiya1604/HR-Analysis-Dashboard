# HR Analysis Dashboard

## 📊 Project Overview

This project is an **HR Analytics Dashboard** developed using **Excel / Google Sheets** to transform a **50,000-record HR employee dataset** into an interactive and business-focused reporting solution.

The dashboard provides insights into **workforce demographics, hiring trends, employee performance, attrition, compensation, attendance, training, and employee development**.

The objective of this project is to help HR teams and management understand workforce trends, identify key HR indicators, and support **data-driven decision-making**.

---

## 📁 Dataset

**Dataset:** `hr_employee_data`

**Number of Records:** 50,000 employees

The dataset contains employee-level information related to:

* Employee demographics
* Department
* Job Role
* Salary and Bonus
* Attendance
* Performance
* Satisfaction
* Engagement
* Work Mode
* Employment Status
* Training
* Experience
* Hire Year
* Promotion
* Attrition
* Overtime
* Annual Leave

## 👩‍💻 Project Purpose

This project was created as a **portfolio project for Data Analytics and HR Analytics** to demonstrate the ability to convert a large employee dataset into a professional, interactive, and management-friendly dashboard.

The dashboard is designed with a focus on **business insights rather than only visualization**, allowing HR stakeholders to quickly identify workforce trends and areas requiring attention.
